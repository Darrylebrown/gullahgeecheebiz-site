# Gullah Geechee Biz — System Overview

## Repository
`~/gullahgeecheebiz-site/` — static site hosted on GitHub Pages

## To Deploy
```bash
cd ~/gullahgeecheebiz-site
git push origin main
```
GitHub Pages auto-deploys from the `main` branch to **gullahgeecheebiz.com**.

## What's Here

### Recipes (`recipes/`)
- 29 Gullah Geechee recipes × 2 languages (EN + ES) = 58 pages
- Full SEO: Recipe schema, OG tags, Twitter Cards, Pinterest rich pins, hreflang
- Index page at `recipes/index.html`
- Daily generator: `scripts/recipe-generator.py` (runs at 4 AM via cron)
- To add more: edit `RECIPES` list in `scripts/recipe-generator.py`

### Workflow Engine (`ggb-engine/`)
Replaces Make.com. Zero dependencies, pure Python.
```bash
cd ggb-engine
./ggb list              # List all workflows
./ggb run <name>        # Run a workflow
./ggb create <name>      # Create a new workflow
```

**Available workflows:**
- `daily-pins` — generate Pinterest pin descriptions
- `daily-book` — generate daily ebook
- `daily-logo` — generate branded logos
- `publishing-content` — articles, social posts, media
- `publishing-production` — build books, pins, assets
- `publishing-distribution` — deploy site, run smoke tests
- `publishing-promotion` — social promotion packages
- `publishing-health` — system health checks
- `master-orchestrator` — runs all daily workflows in order

### Sitemap (`sitemap.xml`)
- 132 URLs, auto-regenerated by `scripts/regenerate-sitemap.py`

### Cron Jobs (Hermes-managed)
All run locally on the M1. Key schedules:
- 2 AM — Backup
- 3 AM — Daily book + Content bot
- 4 AM — Daily pins + Recipe generator
- 5 AM — Daily logo + Production bot
- 6 AM — Viral pages + GPU scavenger
- 7 AM — Maintainer + Viral sellers + Deploy
- 8 AM — Distribution bot + Stripe health
- 9 AM — Health bot
- 10 AM — Promotion bot
- Every 15 min — Security watchdog

### GPU Build
- `gpu-scavenger-daily` — hunts eBay/Craigslist/surplus for free/cheap GPUs (6 AM)
- `gpu-build-weekly` — progress report (Monday 7 AM)
