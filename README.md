# Gullah Geechee Biz

**Preserving a Culture. Telling a Story.**

Gullah Geechee Biz is a culture-first project dedicated to preserving and sharing Gullah Geechee heritage — books, audiobooks, documentaries, merchandise, and the free Corridor Guide.
